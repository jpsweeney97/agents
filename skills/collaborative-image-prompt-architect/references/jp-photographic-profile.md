# JP Photographic Profile

Apply this optional profile only when the user explicitly requests it, the project has already established it, or an otherwise-unspecified candid-photography request is compatible with it. It never overrides an explicit style, target-specific contract, supplied reference, or incompatible medium such as illustration, product hero photography, or polished editorial work.

When active, favor ordinary snapshot realism: observable candidness rather than asserted spontaneity, caused imperfections rather than random defects, and a single frozen reaction with believable biomechanics. Use restrained technical detail only when it supports the visible read. Avoid editorial or cinematic polish when the request leaves candid photographic style open.

Do not leak a device frame, viewer interface, status bar, camera UI, or similar capture-screen artifact into the image. The profile guides compatible completion; it does not authorize a new device, setting, identity, event, or visual thesis.
