# Outside View

The inside view — decompose the task, estimate the parts, sum — is systematically optimistic, because the parts you can enumerate are the parts that go right; that is the planning fallacy. The outside view asks the question the inside view never does: what happened the last several times something in this class was tried?

## The moves

1. **Pin the estimate and its class.** "This migration will take two days" → class: comparable migrations in this repo, by this team. Choose the narrowest class that still has more than a couple of members.
2. **Hunt the base rate in the actual record.** Prefer local records — they encode this team's real friction: git history (first commit to merge for comparable changes), past plan documents versus what actually happened, tracker cycle times. In an organization: pipeline and CRM records, contract logs (intake date to signature date), launch calendars, past project plans versus actuals. Published or industry data only where genuinely comparable.
3. **State the base rate with its sample visible.** "The last four dependency majors here took 3–9 days, median 5 (n=4)." A rate without its n is a vibe wearing a number.
4. **Check what the sample omits.** The record usually contains only survivors — merged branches, signed deals, launched partners; abandoned attempts and dead deals leave no trace in what you queried, so the class's true cost and failure rate are at least what the survivors show. Name the selection effect in one line.
5. **Argue the deltas.** What makes this case genuinely different from the class, in both directions, each delta tied to a named difference — never to confidence or optimism.
6. **Deliver base ± deltas, as an interval.** If step 2 found nothing: say "no reference class reachable — this estimate is inside-view only," widen accordingly, and name what record would calibrate it next time. In an organization, that named record is a process item for whoever owns the tracker — the estimate you couldn't calibrate today is the field someone should start capturing tomorrow.

## The close

No verdict on the plan the estimate lives in; the calibrated interval (or the honest "uncalibrated" flag) is the deliverable.
