# athenahealth Brand System

Apply the official athenahealth brand consistently while preserving the user's factual content and intent.

## Workflow

1. Identify the output format, audience, purpose, channel, and whether the content is internal or external.
2. Read the references needed for the task:
   - Read [references/brand-visual.md](references/brand-visual.md) for any visual artifact.
   - Read [references/color-palette.md](references/color-palette.md) when choosing colors, designing charts, or checking contrast.
   - Read [references/voice-and-style.md](references/voice-and-style.md) for any written content, titles, labels, product messaging, or terminology review.
   - Read [references/assets-and-sources.md](references/assets-and-sources.md) before selecting a template, logo, font, photograph, or icon, or when refreshing this skill from the public brand site.
3. Start from the appropriate official template in `assets/templates/` whenever one exists. Preserve its layouts, masters, theme, styles, logo treatments, margins, and reusable components.
4. Use the bundled Source Sans 3 and PT Serif font files in `assets/fonts/` when the runtime supports font embedding. If embedding is unavailable, keep the named font family in the artifact and disclose any fallback.
5. Use approved assets only. Never redraw, recolor, stretch, crop, rearrange, or synthesize an athenahealth logo. Never invent a brand icon or represent generated imagery as approved brand photography.
6. Adapt the design to the content without forcing every brand element into every artifact. Prefer clarity, simplicity, hierarchy, and generous whitespace.
7. Validate the result before delivery.

## Format-specific rules

### Presentations

- Use `assets/templates/powerpoint/athenahealth_2025_brand_template.pptx` as the starting point.
- Preserve the 16:9 format, master layouts, theme fonts, grid, and logo placement.
- Use concise, sentence-case headlines. Punctuate content-slide headlines that express a complete thought; omit terminal punctuation on title, divider, or section-label slides.
- Use approved tints for charts and data visualization. Keep Hero Purple, cream, and white visually dominant.
- Keep one clear message per slide and avoid decorative complexity.

### Word documents and PDFs

- Select the closest official template from `assets/templates/word/`: FAQ, infosheet, letterhead, one-pager, or long-form.
- Preserve heading styles, header/footer content, page geometry, and logo treatment.
- Use left-aligned body text, short paragraphs, informative headings, and consistent list syntax.
- Export PDFs from the branded source document and visually verify every page.

### Spreadsheets and charts

- Use `assets/templates/excel/athenahealth_excel_template.xlsx` as the starting point.
- Preserve formulas, workbook structure, number formats, theme, and accessibility.
- Use Hero Purple and approved tints as the default chart series. Use secondary colors to distinguish series, never as dominant page backgrounds or body-copy colors.
- Do not use red decoratively; reserve critical red for genuinely critical states.

### Graphics, diagrams, and web content

- Use a 4-, 8-, or 12-column grid based on the complexity and scale.
- Keep equal outer margins and consistent gutters.
- Use the athenahealth holding-shape rules when a branded container is appropriate.
- Maintain approved copy/background combinations and accessible contrast.
- Use photography and icons only as described in the visual reference.

### Writing and messaging

- Sound like a courageous, credible, and compassionate trusted guide.
- Lead with audience benefit, simplify complexity, use specific evidence, and prefer familiar language.
- Follow the athenahealth terminology and AI-naming rules in the writing reference.
- Use `athenahealth` in lowercase. Apply trademark symbols on first reference where required.

## Missing or restricted assets

If a task requires a logo variant, photograph, icon, or motion asset not bundled here, ask the user for the approved Assethub file or direct them to the official collection listed in `references/assets-and-sources.md`. Continue with layout and copy only when doing so will not imply that an unapproved substitute is final.

## Pre-delivery checklist

- Confirm the official template was used when available.
- Confirm Source Sans 3 is primary and PT Serif is limited to approved uses.
- Confirm palette, color proportions, tints, contrast, and critical-state colors are compliant.
- Confirm all logo usage, clearspace, scale, alignment, and placement are compliant.
- Confirm grid, margins, spacing, hierarchy, and holding-shape geometry are consistent.
- Confirm photography and iconography are approved and used within their limits.
- Confirm voice, sentence case, punctuation, terminology, trademarks, and inclusive language.
- Confirm no content is clipped, misaligned, unreadable, or dependent on a missing font.
- Render or preview the entire artifact and inspect it visually before delivery.
