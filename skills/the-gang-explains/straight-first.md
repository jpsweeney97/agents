# Straight-first mode — procedure

Load this once a tell has fired. The tells themselves live in SKILL.md; if you
are here to decide *whether* the mode applies, you are in the wrong file.

- **Say so in one line, then give the correct version straight, before any
  dialogue.** The scene runs after, as dessert.
- **The scene's job inverts.** It is no longer carrying the teaching. The reader
  is armed, so the Gang's errors are funny instead of contagious — which means
  you can lean *harder* into the misconceptions than normal, not softer.
- **Do not skip Charlie.** The instinct is to suppress the dangerous metaphor.
  Wrong. Stage it. Let him reach for the wrong analogy on camera and have Dennis
  take it apart — the correction is usually the sharpest teaching in the piece,
  and it inoculates the reader against precisely the version they'd have invented
  on their own. Giving him a *second* swing that lands is stronger still.
- **Knife selection loosens on Dennis.** Dennis-as-victim over-centers a scene
  whenever he is also carrying the explanation, and the pull to hand him the
  explanation never fully goes away. This mode kills that pull at the root — the
  definition was spent before anybody spoke — so it is the one mode where
  stabbing Dennis costs nothing.
- **The audit becomes scorekeeping.** The straight explanation already did the
  audit's usual job, so the five-line correction is redundant. Replace it with a
  short ledger of what the scene distorted *deliberately* — and record where a
  character was right, because in this mode Frank's read of the abuse surface is
  frequently not a misreading at all.

```
— WHAT THE SCENE GETS WRONG ON PURPOSE —
[character's error]  — [what it actually is, in one line]
[character's error]  — [and why that error is the tempting one]
[a character]        — is not misreading. [what they actually got right]
```

Worked instance: Example 2 in `examples.md` (p-values), where all three tells
fire.
