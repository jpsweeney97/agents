# 2026-09-24 — `decide:design-exploration` 2.7.0: methodology-critique repair forward tests

Uptake evidence for the three text repairs the endorsed methodology-critique brief warranted (`docs/reviews/2026-09-24-design-exploration-methodology-critique.md`, section 9). Proxy passes are uptake evidence, never value evidence: they show whether a fresh agent given the text follows the changed sentence, not whether following it helps a real user. Simulated assent is noise twice over, so every fixture ends on the user's turn and the proxy writes one assistant turn.

Method: 16 headless runs, `claude -p --model sonnet --permission-mode default` with every tool disallowed, prompt piped on stdin, run from the session scratchpad so no repo instructions load, one fresh session per run. Each run received the full `SKILL.md` inline (the bundle has no examples file), a conversation fixture, and the instruction to write only the next assistant turn. Arm A is the 2.6.0 text at `32fa682`; arm B is the 2.7.0 text. Two runs per arm per fixture. Fixtures, runner, and every raw output are in `fixtures/2026-09-24-design-exploration-2.7.0/`. Proxies were not told which arm they held. The judge (the treatment session) graded by reading all 16 outputs. All fixtures use invented codebases (a notes CLI, a bookmarks API); nothing in them is from a real fire.

## What this shows and does not show

- Repair 1 (the ungated offer) discriminates cleanly on f1 (0/2 against 2/2) and shows uptake on every other fixture (B offered pressure 8/8; A 0/8). The sentence "where no pressure ran, the premises get their first test downstream" appears in B 8/8 and A 0/8.
- Repair 2's "whose words approved" beat discriminates cleanly on f3 (relayed approval accepted 2/2 against refused 2/2) and shows uptake on f2 (2/2 against 0/2). Its "accepted as offered by default" clause did not discriminate: the old text's agents graded the self-review patch accurately on f2. That half is graded untested, not passed; the fire that motivated it (51bf, "all decisions JP-ruled") was a long work-repo conversation a four-turn fixture does not reproduce.
- Repair 3 (the widened tell) is partial: the `prototype` offer appears in B 2/2 and A 1/2 (as an unnamed throwaway check). The observed-vocabulary list did not itself discriminate on this fixture.
- Nothing here reaches Codex, a real user's reply, a relayed review that read code, or a conversation longer than five turns. Whether a real user takes an ungated offer more often, and whether the "first test downstream" sentence changes what an approval is taken to mean, are for the next fires.
- Two runs per arm is a sample, not a rate.
