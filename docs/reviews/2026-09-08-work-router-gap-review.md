### C1 — medium — Step 2 treats the model-visible skill listing as complete; it is not, in two ways the text never states (finding-01 + finding-02; gap)

**Confirmed by reasoning (reproduced=false for both parts).**

- **C1a — elided descriptions (medium).** Claude Code drops descriptions from the skill listing, least-invoked first, when the listing exceeds its character budget; every name stays. On this machine the budget is a fixed 50,000 characters (`SLASH_COMMAND_TOOL_CHAR_BUDGET` in `~/.claude/settings.json` env), and the library's 122 descriptions total 55,905 characters before third-party and bundled skills, so overflow is certain (margin ~1.1×). Observed in both the coordinator session and the verifier session: ~50 name-only entries, including lanes work-router itself names (`simplify-code`, `outcome-shaping`, `ideate`, `option-shaping`, `design-exploration`). Line 29 ("Inspect available skill descriptions first… deep-read only the likely overlapping `SKILL.md` files") presupposes a description to judge overlap from, and line 62's `Checked: <skill descriptions…>` would be written in good faith while overclaiming. Nothing in AGENTS.md, `docs/agents/`, or the target mentions the truncation. Verifier corrections: the candidate set is not narrowed (names remain), what is lost is the description-based overlap step; drop order follows Claude Code's own `skillUsage` counter in `~/.claude.json`, not the repo ledger, with zero-count ties broken unpredictably; the listing carries no marker distinguishing elided from absent.
- **C1b — hidden explicit-only lanes (low).** Eight live skills carry `disable-model-invocation: true` in frontmatter (`next-steps`, `plain-language`, `to-questionnaire`, `zoom-out`, `teach`, `setup-matt-pocock-skills`, `review-reviewer`, `gh-pr-review-loop`); six of them also set `allow_implicit_invocation: false` for Codex. They are absent from the roster step 2 inspects, and the body names only `next-steps` (line 95). Commit `cebf8e9` removed the one sentence that had explained the hidden class. **Verifier contradicted the predicted consequence:** in 5/5 blind proxy runs (Fable ×4, Sonnet ×1) on hidden-owner inputs, the agent listed `~/.claude/skills` unprompted and routed to the hidden owner correctly, listing explicit invocation under Before starting. Two mitigations both reviewers missed: the tested hidden owners are named in the bodies of visible neighbors step 2 would deep-read, and two others appear in visible frontmatter descriptions. What survives is that correct routing to a hidden lane rests on unrequired model initiative, not on any sentence in the target.

Shared root cause: the text has no sentence saying the listing can be incomplete or what to do about a name-only or absent candidate.

### C5 — medium — When a request pairs an explicit skill invocation with a routing check, the text does not say whether the invoked skill proceeds after the check (finding-12; contract-defect)

**Reproduced** (blind proxies, `repro/12`). Line 24 permits work-router to act when the user "also asks for a routing check", and its second sentence ("ask before switching") presupposes that execution continues after the check. Under render-and-stop the explicit request is dropped and the compact template (line 73) tells the user to re-type what they typed; under proceed, the session runs the downstream skill, which step 6 forbids in so many words. **Corrections:** "override" is neither undefined nor vacuous — because the router stops the turn, firing it displaces the invoked skill's execution, and that displacement is what line 24 names; the "two risk prescriptions" sub-claim does not hold (line 24's second sentence is scoped to the invoked lane looking dangerous, line 102 to any recommended route needing unsafe action; complementary); and the proceed reading also needs step 6 re-scoped or the surfaces still disagree. Medium at its low end: the stop condition is the trust-shaped part of this skill, but the combined invocation-plus-check form is uncommon (ledger: no user-initiated Claude fires). Limit: proxies were self-narration with tools disabled; the model-initiated variant ("work out the right skill for this and run it") was not run.
