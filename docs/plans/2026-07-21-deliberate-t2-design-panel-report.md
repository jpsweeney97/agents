# T2 design panel report: the deliberate shallow-prune control pre-registration

The adversarial design panel the unsealed prereg requires before sealing (its move 7). Five reviewers attacked the draft independently against the pilot's verbatim artifacts. This report is the panel's consolidated product: the formal gate position, the consensus repairs, the contested calls JP must adjudicate, and the feasibility checks owed before seal. It is design input only; nothing here is sealed evidence.

Process disclosure: the methodology seat initially misdelivered its report to the control seat instead of the main session; the control seat's report had already been delivered before that misdelivery, and the methodology seat re-sent with an explicit assertion that it incorporated nothing from the control seat. The gates seat delivered on a second prompt. All five reports arrived complete; no reviewer saw another's findings before delivering its own, with the one disclosed seam above.

## Formal gate position (methodology seat)

As drafted the protocol does not satisfy the spec gate at `docs/specs/2026-07-13-deliberate.md:442`: the pilot refutes the drafted replication design, and the winner-set mapping the draft calls "mechanical" is operator judgment. All five elements the gate names (same-field control, winner adjudication, leakage boundary, case set, pass/fail rule) are present, so the deficiencies are within-structure fixes. The seat's position: satisfied conditional on the replication repair, the single-variable repairs, the seal-provenance rule, the extraction repair, and the verdict-wording bounds — all carried below.

Eight-move audit summary: moves 6 (pilot), 7 (this panel), 8 (null honesty) satisfied; move 5 (human cold judge) satisfied with residuals (JP is not authorship-naive; an empty channel spends no anchor); moves 1–4 partial (seal provenance, single-variable bundle, under-powered replication, arm monoculture — each repaired below).

## Panel consensus — adopt at revision

Each item names its fix and the seats that independently demanded it. No seat dissents from any item in this list.

1. **Strike the pilot-liveness clause from CALIBRATED** (gates, control, measurement; methodology adjacent). Delete "or the pilot proved the channel can fire" — it launders excluded, confounded pilot data into the sealed verdict and lets a control too diluted to ever crown anyone certify the prune safe. CALIBRATED requires the sealed run to demonstrate its own non-empty channel; zero sealed-run divergences → INCONCLUSIVE, never CALIBRATED. Add a pre-registered ARM C health floor: a minimum share of committal (non-check-first) closes for the run to be readable.
2. **Delete the whole-run stability kill** (gates, control, measurement). At the pilot's measured 1-of-3 pairwise agreement, the drafted two-probe whole-run kill starves the entire run with probability ≈ 89% (point estimate, n=1 case, directional). Replace with per-case handling: a case whose ARM C output cannot support extraction routes that case to INCONCLUSIVE with a reserve-pool replacement; the run never dies on a probe.
3. **Seam-free adjudication and control surfaces** (all five seats, from independent directions: the seams unblind judges, inflate crownings, and add an uncontrolled variable). Flat markerless merge with no batch/pass boundaries; style homogenization across batch shapers; a pre-registered seam-leak scan that flags and re-runs any ARM C rep whose close cites pass/batch structure (the pilot's rep 3 demonstrates the need); adjudication packets never carry field-width, option counts, numeric-vs-alpha labeling, batch vocabulary, or apparatus vocabulary.
4. **Arm-blind packet regeneration with an executed leak probe** (leakage, control, methodology). Candidate cases in any adjudication packet are regenerated by a fresh arm-blind rewriter to a fixed template from the frozen decision facts plus the candidate's substantive case — never passed through from a shaping stage. Verification is an executed probe: a fresh blind agent is asked to recover field-width and process; recovery fails or the packet is rebuilt.
5. **Neutral re-shape before adjudication** (control, the load-bearing construction; composes with items 3–4). For every adjudicated divergence, both the excluded candidate and ARM P's winner are re-shaped under one identical neutral, seam-free, single-pass condition, and the head-to-head is judged over that surface — never over ARM C's wide batched shaping, which is the instrument under test and the only other source of a shaped case for the excluded candidate. The re-shape procedure is sealed as protocol.
6. **Sequester the human arm** (leakage, gates adjacent). No sealed-run divergence outcome, panel score, or count is written to any repo doc or any channel JP observes until his cold-judge adjudications are recorded; JP's packets are delivered out-of-band, composed by a fresh blind agent, with decoy packets (divergences where ARM P's winner is stronger, and ties) so his discrimination is measurable; the trigger for which divergences reach him is mechanical and pre-registered, never operator selection. Working stores live outside the repo and outside JP's normal read paths.
7. **Blind roles are sandboxed, not merely fresh** (leakage). Case-writers, judges, and packet composers run with read scope confined to a packet directory outside the repo tree, enforced at dispatch — a fresh agent with filesystem access can otherwise read the committed prereg and pilot report, which name the hypothesis and the pilot's divergent candidate.
8. **Operator-to-judge channels sealed** (leakage, methodology). Byte-identical pinned dispatch prompts across judge dispatches; A/B position randomization keyed off the sealed map with a committed seed; follow-ups pre-scripted or forbidden, all logged.
9. **Sealed-map custody made auditable** (leakage). At seal, the keying map's SHA-256 is recorded inside the committed prereg; the map lives at a named location outside every dispatched agent's read scope and outside JP's read paths; at unblind the map is revealed and verified against the sealed hash.
10. **Case source: authored-blind with a mechanical admission checklist, stratified by fact-density** (leakage, measurement). The word-list defense is theater against field-shape selection; discretionary shape-screening by the hypothesis-aware operator is replaced by a pre-registered mechanical admission checklist. Preferred over adapted-historical cases, which leak recognizable content and known outcomes. Fact-density is measured by a hypothesis-blind metric and the case set spans declared density bands under a fixed quota (roughly half specified, half sparse), screened by a counter who never sees the hypothesis; divergence and INCONCLUSIVE rates are reported by stratum, and a density–INCONCLUSIVE correlation is a measurement limitation, never folded into the prune verdict.
11. **Candidate identity pinned at stem-freeze** (measurement, gates dependent on it). A crosswalk from each generated-field canonical wording to a stable candidate ID is produced when the shared field is frozen and used by both arms and by extraction; a winner that matches no generated wording under the pre-declared rule routes the case-rep to INCONCLUSIVE, never to an operator match.
12. **Attrition dispositions per failure mode, with a timing firewall** (measurement, gates adjacent). Pre-registered dispositions for ARM C batch/envelope failure (capped mechanical retries, then void-and-replace), store loss (non-resumable void-and-replace), ARM P honest exit after Prune (a distinct "ARM P declined" cell that never feeds the divergence gate — naming no winner is not excluding one), and reserve-pool exhaustion (N caps at achieved count, disclosed, never backfilled). Every void/retry decision is timestamp-logged before that arm's winner-set is extracted; a void decided after a winner-set is seen is forbidden and the case is retained.
13. **Descriptive-measures firewall** (measurement; the pilot already used Prune-record anticipation interpretively to soften the divergence). Sealed sentence: no descriptive measure may reclassify, mitigate, or discount any adjudicated excluded-eventual-winner count or the verdict it produces; the verdict is computed from adjudicated counts alone and recorded before any descriptive measure is consulted.
14. **Map the `your call` close shape and plural comparators before seal** (measurement, gates). `your call` maps to the presented option heads in the secondary channel, never the primary gate. When ARM P's winner-set is plural, the excluded candidate must be adjudicated strictly stronger than every ARM P branch head to count as damage — fixed mechanically in the mapping, not chosen at adjudication time.
15. **Seal provenance rule** (methodology). The existing draft commit is the immutable pre-pilot record and its SHA is cited in the seal; every pilot-informed value is marked "revised post-pilot" with the pilot base rate; the seal certifies that predictions preceded the sealed run's data, never the pilot's.
16. **ARM C named and bounded as a synthetic instrument** (control, methodology). The shipped product has no full-field shaping mode; ARM C's construction (batch size, shaping model, merge rule, per-shaper candidate visibility, isolation properties, the identity-Prune scaffolding) is sealed as disclosed protocol, and every ARM C-derived claim is bounded to "under this synthetic full-field shaping procedure," never "full shaping" unqualified. Symmetric scaffolding (schema note, relay-note transport, batching rule) is present identically from dispatch 1 in both arms; the Recommend-equivalent brief spec is frozen; the pilot's non-survivor-bytes-identical merge check is promoted into sealed protocol.
17. **Verdict wording bounds** (methodology, gates). Drop "net-protective" (the experiment tests do-no-harm, never benefit); attach the same-family-arms bound and the population/model/harness bound to every verdict, not only the null line; the verdict template states that a zero-divergence result is consistent with both "safe" and "instrument-blind" absent a passed positive control.
18. **Budget in dispatch-count and operator-hours, with byte-proxy instrumentation** (measurement). The pilot never priced tokens (bytes and wall-clock only), and the binding constraint it actually hit was operator attention: ≈ 15–17 dispatches per case, ≈ 120+ at N=8, at the pilot's ~19% kill rate. Per-dispatch records pin stage, arm, rep, brief/envelope bytes, wall-clock, model, and runtime token counts only if the harness exposes them (flagged as estimates otherwise). Cost cut with least validity loss: ARM P's second rep runs prune-only — its exclusion set is all the design needs from it.
19. **Cross-family adjudication provisioned and piloted before seal** (leakage). The FALSIFIED verdict leans on cross-family corroboration, but the pilot convened no panel at all; the blind cross-family channel (packet delivery to a non-Claude model, judgment capture, blinding held) must be demonstrated end-to-end before seal, with ≥2 cross-family judges so corroboration is not a single point of failure, and the same-family/cross-family split rule pre-registered. If the channel cannot be shown to fire, the run's ceiling is INCONCLUSIVE and the seal must say so.

## Contested calls — JP adjudicates

**A. Winner-set extraction mechanism.** The pilot's own proposal and two seats (methodology, gates) want each Recommend envelope to declare its winner-set as a structured machine-readable artifact, removing operator extraction. The measurement seat rejects the declaration outright: added to ARM C only it breaks the single-variable differential; added to both arms it means ARM P is no longer the shipped pipeline; and it would push recommenders to collapse genuine values-forks into named heads — contaminating the behavior under test toward more crownings. Its alternative: extraction by ≥2 blind sandboxed extractors applying a pre-registered codebook to close text only, inter-rater agreement measured, disagreement routing the case-rep to INCONCLUSIVE — combined with tiering by close shape (only clear-call crownings feed the primary FALSIFIED gate; check-first/conditional branch heads feed a labeled secondary channel, since a check-first close is a refusal to crown, not a revealed winner). The measurement seat demonstrated the stakes by re-extracting the pilot's four closes: the pilot's "1 of 3 divergence" headline holds only under an inconsistent standard — consistent-strict gives 1/3, consistent-generous gives 3/3, and the inconsistency fell exactly on the two excluded-set contenders. Numerically the panel splits 2–1 for declaration, but the codebook uniquely answers the contamination objection and equally removes operator discretion. Synthesis lean: blind dual-extractor codebook plus close-shape tiering; no declaration obligation in either arm.

**B. What counts as damage — reproduction versus adjudication survival.** Gates and methodology: a divergence is gate-eligible only when the same excluded candidate is crowned in ≥2 of k ARM C reps, applied identically to the rate gate and the existence finding — otherwise ARM C noise manufactures divergences, and the existence finding elevates a lone noise-surfaced crowning into a "confirmed damage" headline the blind head-to-head cannot deconfound (the judge never learns the candidate was crowned once in k tries, and head-to-head strength-in-isolation is a different question from what full shaping crowns). Control: never filter divergences by frequency — at the observed 1-of-3 detection reliability a reproduction gate discards roughly half of genuine catches at k=5, the check-first reps it treats as contradiction are actually abstentions, and the honest separator is survival of the hardened (re-shaped, seam-free) adjudication, with reproduction rate recorded descriptively. The disagreement is about the thesis itself: is a candidate that full shaping crowns only rarely, but that survives a clean blind head-to-head, a "revealed winner"? This is the deepest open parameter; the k choice (call C) and the existence finding's grain both hang on it. Composite option available: reproduction-gated primary rate gate plus an adjudication-survival existence channel that must disclose its reproduction rate — at the cost of the two channels answering slightly different questions, disclosed.

**C. ARM C rep count k.** All seats agree the draft's asymmetry is backwards (two reps for the stable prune arm, one for the noisy detector) and that extra ARM C reps are cheap — the shaping is once-per-case and reps re-run only the recommender over the shared brief. Proposals: k≥3 (methodology), k≥5 (control; measurement concurs on affordability), k=7 at observed variance or k=5 after variance reduction (gates, with binomial power arithmetic: ≥2-of-k reproduction against 1/3 detection reliability gives per-case power ≈ 0.54 at k=5, ≈ 0.74 at k=7, ≈ 0.86 at k=9). If call B lands on adjudication-survival, k=5 suffices for detection; if reproduction-gated, k=7 is the defensible floor absent a variance-reduction demonstration. ARM P at 2–3 reps, second rep prune-only.

**D. ARM P exclusion qualification under prune stochasticity.** Gates: a candidate qualifies as prune-excluded for divergence purposes only when excluded in both ARM P reps — a candidate the pipeline only sometimes cuts is not reliably excluded, and the liberal reading inflates the divergence surface. Control: check divergences against the union of both reps' exclusion sets so a divergence is tested against every rep's exclusions. The conservative reading narrows the thesis to systematic exclusion; the liberal reading captures stochastic damage at the cost of half-true "the prune excluded it" claims. Synthesis lean: both-reps qualification for the gate, union recorded descriptively.

**E. The positive-control case.** Gates (alone, but load-bearing if adopted): construct one sealed case seeded with a candidate designed to dominate the field yet be force-excluded by the survivor budget; the instrument catching it becomes a precondition for CALIBRATED — the only demonstration that separates "prune is safe" from "instrument is blind." Costs: one case slot, design effort, and a leakage-compatible blind construction path (the planted case must be authored without contaminating the case-writer machinery; the leakage seat's mechanical-admission machinery would need a carve-out, itself a leak surface). No other seat proposed it; the sealed-run-divergence requirement (consensus item 1) is the weaker substitute already adopted. Adopt, adapt, or decline.

**F. N, the FALSIFIED threshold, and the minimum detectable damage rate.** Gates: do not seal a bare integer — pre-register the minimum detectable damage rate and derive threshold and N from a binomial power calculation; at N=8 and threshold 2, a prune with a true 10% per-case damage rate is exonerated ~81% of the time, so CALIBRATED at N=8 must read "no detectable damage at roughly a 25% case rate or above," with the low-rate regime owned by the (call-B-gated) existence channel. Keeping N=8 is defensible with that disclosure; detecting ~15% damage pushes N toward 20 — a cost call. Measurement's arithmetic: N=8 is affordable on tokens; the binding ceiling is operator attention across 120+ dispatches.

**G. Sequencing — a bounded second pilot before seal.** Gates wants a 2–3 case instability mini-pilot after the variance-reduction changes land, to measure whether per-rep detection reliability rises enough for the chosen k to carry power, plus a sealed instrument-fitness precondition (if no modal winner-set is establishable at the chosen k on a majority of cases, the run does not proceed). The first pilot's own report deferred its optional second case to exactly this post-revision moment, and the measurement seat's health floor needs a base rate to be set against. Synthesis lean: adopt — revise the draft per this panel, run the bounded mini-pilot, fix k and the thresholds from its measurements, then seal.

## Feasibility checks owed before seal

- Whether dispatch-time read-scope confinement (consensus item 7) is actually enforceable for subagents on this machine, versus instruction-level confinement — the leakage seat's fix presumes enforcement.
- Whether a blind cross-family judge (consensus item 19) is dispatchable and capturable end-to-end on this machine; unproven, and the FALSIFIED ceiling depends on it.
- Whether the harness exposes per-subagent token usage (consensus item 18); the pilot's silence suggests not, in which case the byte-proxy floor is the sealed instrument.
- The ARM C shaped surface for the pilot's divergent candidate was never read verbatim by the control seat (the appendices carry closes and hashes, not the 85KB surface); pulling it would confirm or refute the shaping-provenance inference behind consensus item 5's motivation, though the fix stands on construction grounds either way.

## Bounds

Every power figure and starvation estimate in this report rests on the pilot's single case (pairwise agreement 1 of 3); the real variance distribution across cases is unknown until the mini-pilot. The adjudication layer's behavior under load — judge agreement rates, cross-family behavior, tie frequency on fact-sparse fields — is entirely unmeasured (no judge was spent in the pilot, by design). The measurement seat's 3-of-3 re-extraction of the pilot closes is itself a single-extractor reading, offered as proof of discretion-sensitivity, not as a corrected count. No reviewer re-ran any arm, read the 10,789-line validator, or re-verified the pilot's hash ledger; pilot testimony was taken at its stated grade. The five reports reflect five independent single-lens passes at one commit; this synthesis is the orchestrating session's, and JP's adjudication of the contested calls is its authorization, not verification.

## Addendum (2026-07-21, post-synthesis): the control seat's reconciliation of call B

Provenance and independence: after this report was landed, the control seat sent an unsolicited cross-panel reconciliation of call B. It is not independent — the control seat had read the methodology seat's audit through the misdelivery disclosed above — so it carries the weight of an argued rebuttal, not a fresh lens. Its original report predates any contamination; only this addendum's content is post-contact. Recorded here appends-only; the settled sections above are unchanged.

The reconciliation claim: the conflict dissolves rather than splits, because the reproduction filter is a symptom-treatment for the leaky adjudication of the control seat's Finding 1. With adjudication hardened (consensus item 5's neutral re-shape), a noise crowning fails adjudication and a rare true catch survives it — so the filter becomes redundant for noise suppression and harmful to the low-frequency catches. Fix order matters: harden adjudication first, then do not seal a reproduction filter. The control seat therefore accepts the methodology seat's raised k (convergent with its own Finding 7) while rejecting its ≥2-of-k gate-eligibility rule.

Three specifics the reconciliation adds beyond the original reports: the reproduction filter silently overturns two pre-registered gate elements (the FALSIFIED gate's "any rep" and the n=1 existence finding) and should be named a gate redefinition, not a parameter tweak; the proposed modal/majority winner-set rule is undefined on the only data in existence — the pilot's three winner-sets are all distinct, so no mode exists, and relaxing to modal-winner discards the divergence; and a majority rule reads the two check-first reps as votes against the divergence when they are abstentions, not contradictions.

Reinforcements it folds in from the methodology seat: the same-family monoculture bound and the under-sampling failure mode push in the same dangerous direction, so a CALIBRATED result must read "no excluded winner found by a same-family full-shaping control," never "the prune is worth trusting"; "net-protective" should be dropped (already consensus item 17). One limit it adds to consensus item 16: the non-survivor-bytes-identical merge check proves candidate wordings are stable, not that the splice-merge preserved shaped-consequence semantics — seal the check, but never quote it as full ARM C fidelity proof.

Synthesis note: the reconciliation defeats the noise-suppression rationale for the reproduction filter, and its undefined-modal-rule observation is a hard fact against sealing that rule as drafted. What it does not answer is the gates seat's thesis-level objection (its CRITICAL 3): a blind head-to-head measures strength in isolation, which is a different question from what full shaping crowns, so adjudication survival alone also does not establish "revealed winner" for a candidate crowned once in k reps. Call B therefore narrows but does not close: with hardened adjudication adopted, the residual decision is definitional — what claim a non-reproducing, adjudication-surviving divergence licenses — and it remains JP's, with the composite option (reproduction-gated rate gate plus a survival-based existence channel that must disclose its reproduction rate) still on the table.
